# Unit 1: Practice Quiz

!!! information

    *Ungraded self-check — use this to prepare for Quiz 1. Answer key is at the bottom; don't peek until you've tried every question. Covers the same skills as the real quiz: ASCII, binary conversion, binary addition, binary multiplication, and Scratch block tracing.*

    1. Using the ASCII chart, what is the decimal representation of `"cat"`?
    - A. cat
    - B. 99 97 116
    - C. 97 99 116
    - D. (it can't be represented as decimals)

    2. Convert binary `11010` to decimal: _______

    3. Convert decimal `19` to binary: _______

    4. Convert binary `01100` to decimal: _______

    5. Add the following binary numbers, showing your work:
    ```
      1001
    + 0111
    ```

    6. Both numbers below are in binary. Select the **decimal** representation of the answer.

    `110 × 101`
    - A. 30
    - B. 11110
    - C. 15
    - D. 25

    7. A Scratch program contains the following blocks:
    ```
    when [green flag] clicked
    repeat (5)
      move (50) steps
      turn (72) degrees
    ```
    What path does the sprite trace?
    - A. A straight line
    - B. A triangle
    - C. A pentagon
    - D. A circle

    ---

    ### Answer Key

    1. **B.** `99 97 116` — ASCII: c=99, a=97, t=116

    2. **26** — `11010` = 16+8+0+2+0

    3. **10011** — 19 in binary

    4. **12** — `01100` = 0+8+4+0+0

    5. **10000** — `1001 (9) + 0111 (7) = 16`

    6. **A. 30** — `110 (6) × 101 (5) = 30` decimal (B is the binary form, not decimal)

    7. **C. A pentagon** — repeat(5): move + turn 72° five times traces a 5-sided shape (5 × 72 = 360°)

    **Study tip:** if you missed any binary conversion or arithmetic question, go back to Chapter 2/3's notes and redo the division/place-value steps by hand — don't just memorize this quiz's specific numbers.
